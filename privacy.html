プライバシーポリシー

最終更新日：2026年10月9日

このページは、個人用の自動化ツール（morning-brief、youtube-organizer）が Google のデータをどう扱うかの説明です。これらのツールは作成者本人だけが自分のアカウントで使っており、ほかの人には提供していません。

使うデータ

  • morning-brief：Google カレンダーの予定と Gmail のメールを読み取りのみで使います（Google の許可の範囲：calendar.readonly、gmail.readonly）。
  • youtube-organizer：本人の YouTube チャンネルの動画の題名・タグ・再生リストを読み取り、整理のために変更します（Google の許可の範囲：youtube）。

データの扱い

  • データは本人のパソコンの中だけで処理し、結果は本人のスマートフォンにだけ通知します。
  • データを販売したり、広告に使ったり、第三者に渡したりしません。
  • メールの要約のために、本文の一部を AI のサービス（Google Gemini API）に送ることがあります。
  • Google の許可証は本人のパソコンにだけ保存します。

Google API サービスのユーザーデータ ポリシー

これらのツールによる Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータ ポリシー（限定使用の要件を含む）に従います。

許可の取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
